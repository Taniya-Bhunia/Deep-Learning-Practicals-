# Deep Learning Lab Practicals

A collection of 10 hands-on Deep Learning laboratory practicals implemented using Python. This repository covers fundamental neural network concepts, learning algorithms, optimization techniques, activation functions, dimensionality reduction, and autoencoders.

This project is part of my **B.Tech in Computer Science and Engineering (Artificial Intelligence and Machine Learning)** coursework. It documents my practical learning and implementation of important Deep Learning concepts.

## About This Repository

The repository contains 10 Deep Learning practicals, implemented and organized in a Google Colab notebook. Each practical focuses on understanding a specific concept through Python programming, experimentation, and model evaluation.

The main objective is to develop a practical understanding of how neural networks work, how they learn from data, and how different Deep Learning techniques can be applied to real-world problems.

## List of Practicals

| No. | Practical Title | Description |
|---|---|---|
| 01 | McCulloch-Pitts Neuron | Implemented a McCulloch-Pitts neuron to perform the AND logical operation. |
| 02 | Multilayer Perceptron (MLP) | Implemented an MLP using NumPy to classify handwritten digits from the MNIST dataset. |
| 03 | Feedforward Neural Network | Implemented a feedforward neural network using Sigmoid and Softmax activation functions on the Iris dataset. |
| 04 | Backpropagation Algorithm | Implemented backpropagation with gradient descent to train a single-hidden-layer neural network on the XOR problem. |
| 05 | Resilient Propagation (RPROP) | Implemented the RPROP optimization algorithm and tested its performance on XOR classification. |
| 06 | RBF Network vs MLP | Compared the approximation capabilities of Radial Basis Function networks and Multilayer Perceptrons. |
| 07 | Activation Function Comparison | Compared ReLU, Leaky ReLU, and ELU activation functions using a CNN on the CIFAR-10 dataset. |
| 08 | Nesterov Accelerated Gradient | Compared Nesterov Accelerated Gradient (NAG) with standard Gradient Descent using a neural network on MNIST. |
| 09 | Principal Component Analysis (PCA) | Applied PCA to the MNIST dataset and visualized the first two principal components. |
| 10 | Denoising Autoencoder | Implemented a denoising autoencoder on Fashion-MNIST to reconstruct images corrupted by noise. |

## Technologies and Libraries Used

The following tools and libraries are used throughout the practical implementations:

- **Python** – Primary programming language.
- **NumPy** – Numerical computations and matrix operations.
- **Pandas** – Data handling and manipulation.
- **Matplotlib** – Data visualization and plotting.
- **Seaborn** – Statistical data visualization.
- **Scikit-learn** – Machine learning algorithms, preprocessing, and evaluation.
- **TensorFlow & Keras** – Neural network and Deep Learning model development.
- **Google Colab** – Cloud-based environment for writing and executing Python code.

## Datasets Used

The practicals use the following datasets:

- **MNIST:** Handwritten digit recognition and dimensionality reduction.
- **Iris:** Classification using a feedforward neural network.
- **CIFAR-10:** Image classification using convolutional neural networks.
- **Fashion-MNIST:** Image denoising and reconstruction.
- **XOR Dataset:** Understanding neural network learning and optimization.
- **Synthetic Sine Dataset:** Comparing RBF and MLP approximation performance.
